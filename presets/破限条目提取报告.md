# AnimaTagger 图片反推预设使用说明

预设文件：`梦鲸思客-AnimaTagger反推预设V1.json`，适用于 SillyTavern 聊天补全配置。提示词生成流程、角色候选规则和输出格式以 `SKILL.md` 及对应分支指南为准。

## 使用方法

1. 在 SillyTavern 的聊天补全预设页面导入该 JSON 文件。
2. 确保模型能读取 `SKILL.md`、`references/反推分支.md` 和 `references/格式规范.md`，并具备调用本地打标与校验工具的方式。
3. 选择支持图片输入的模型，发送参考图和所需的反推要求。
4. 模型按技能生成提示词；交付前执行完整 tag＋自然语言校验。

## 配置

- 预设包含 21 个条目，默认启用 17 个。
- `[选开]` 条目包括思考强度低／高、DeepSeek 思考标记和预填充，默认关闭；按模型能力选择适用项。
- 默认采样参数为 `temperature=1`、`top_p=0.95`，可根据使用的模型调整。
- 角色卡、世界书、场景与聊天记录由 SillyTavern 对应功能提供。
- 梦境格式专用正则处于禁用状态，避免改写反推标签或将输出包装成思考区块。

## 导入与修改检查

- 文件须为合法 JSON；`prompt_order` 中的标识符应与 `prompts` 一致，无重复或缺失。
- 确保输入条目能传递当前用户消息与图片。
- 若模型无法访问技能文档或运行本地工具，应先配置这些能力；仅导入聊天预设不能完成本地打标。
