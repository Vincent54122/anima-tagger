# 格式规范

## 一、硬规则

| # | 规则 |
|---|---|
| 1 | 分隔符**必须是 `", "`**（逗号 + 一个空格）。写成 `a,b,c` 会改变分词边界，造成 tag 吸附/串味 |
| 2 | tag **全小写** |
| 3 | **下划线换成空格**：`ui_(blue_archive)` → `ui (blue archive)` |
| 4 | **括号保留**，不要加反斜杠转义 |
| 5 | 总长上限 **512 token**（tag 层 ＋ NL 层 ＋ 空行都算） |
| 6 | 权重写成 `(tag:1.2)`，**能不用就不用** |

### 权重语法

| 写法 | 结果 |
|---|---|
| `(tag:1.2)` `(tag:.5)` | 生效 |
| `((tag))` | 1.21（1.1²） |
| `[tag]` | 字面字符，**不降权** |
| `[[tag]]`、`(tag)1.2` | 不支持 |
| `BREAK` | **不支持，不要用** |

## 二、槽位顺序

```
[rating] → [人数] → [character] → [外貌] → [服装·配饰·道具]
        → [动作·姿势·表情·视线] → [镜头·构图] → [场景·背景·氛围] → [NL]
```

| 槽 | 装什么 |
|---|---|
| rating | `general` / `sensitive` / `questionable` / `explicit` |
| 人数 | `1girl` / `2girls`… ＋ `solo`（仅单人） |
| character | 角色 tag，如 `ui (blue archive)` |
| 外貌 | 发长·发色·瞳色·体征 |
| 服装·配饰·道具 | 品类 ＋ 材质 ＋ 状态 |
| 动作·姿势·表情·视线 | 姿势一律用 tag |
| 镜头·构图 | 取景 / 视角 / 焦点 |
| 场景·背景·氛围 | 场所 > 物件 > 时间天气 > 光影 |
| NL | 空间关系 / 光影 / 景深 / 因果 |

## 三、排版

逻辑上是一条 `", "` 流，**空行只是排版**。单人：

```
general, 1girl, solo,

ui (blue archive),

black hair, very long hair, blue eyes, halo,

white serafuku, purple neckerchief, grey cardigan,

standing, looking at viewer, holding book,

cowboy shot, depth of field,

blue background, gradient background,

Place the character slightly right of center, Use soft light from the left,
Keep the face sharp against a softly blurred background.
```

多人：**每人一段**，段间空行。**用外观指认，不要用 `Character 1/2`，不要用 BREAK**。

```
2girls,

<全局：场景 · 背景 · 镜头 · 光影>,

<A 的外观 · 服装 · 表情 tag>,

<B 的外观 · 服装 · 表情 tag>,

Place <外观指认 A> on the front left, <A 的动作>,
Place <外观指认 B> on the front right, <B 的动作>,

<收尾句：关系 / 接触点归属 / 景深>
```

NL 段直接写句子，**不加引号**。

## 四、禁用清单

| 项 | 说明 |
|---|---|
| 质量前缀 | `masterpiece` `best quality` `score_9` `very aesthetic` 一律不写 |
| 负面提示词 | 不产出 |
| 画师 tag | 不产出 |
| 独立作品 tag | 不产出（角色 tag 自带作品信息） |
| `BREAK` | 不支持 |
| `[[tag]]` `(tag)1.2` | 不支持 |
| 引号包整段 | 会被当成要渲染的文字 |

## 五、超预算了怎么办

**超预算就是 NL 太长**，不要动 tag。

校验器会直接报出这个数：`[token] 562 / 上限 512　·　tag 层 291　→　NL 最多 221`。
tag 层是固定开支——实测在 0.35 阈值下，最复杂的图 tag 层也只到 291，要撑满 512
得把 tag 数翻近一倍。所以正常情况超预算一定是 NL 的锅。

### 为什么不能放着不管

超出的部分**不是权重变弱，是从尾部整块消失**。Anima 把提示词切成 token 位置，
第 512 个之后的位置根本不存在，画图模型看不到它们。

而 NL 排在槽位顺序的最后，所以**先死的永远是 NL**——还是在 token 边界上**拦腰砍断**，
留下半句坏指令。主动精简，等于把"随机砍断"换成"你选着删"。

### 怎么精简

从上往下，够用就停：

1. **压措辞** —— 删形容词、副词、重复的限定语，句子骨架不动。
   `Use soft warm light from the left` → `Use soft light from the left`
2. **并句** —— 同一岗位的两句合成一句。
3. **删句** —— 整句删，从**最没信息量**的那句开始。

删句时优先砍这些：写了等于没写的（`Keep the face sharp` 这种默认就该这样的）、
画面本来就成立的。**优先保住 ①编剧（正在发生的那一下）和 ②监督（空间与层次）**——
这两样没了成品最容易垮；③原画、④摄影相对可压。

### 改完必须重跑

```powershell
& $PY "$SKILL\tools\anima_validate.py" --tags "<成品 tag 串>" --nl "<精简后的 NL>"
```

跑到不报超预算为止。**改动要在末尾附注一行**（铁律 8），写清删了哪句。
