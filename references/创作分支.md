# 创作分支（文字 → 提示词）

没有图片时使用。输出形态与反推分支相同，格式见 `格式规范.md`。

---

## 1 · 需求分档

判据：用户的话里能不能同时读出 **谁 / 在哪 / 什么调子**。

| 档 | 用户给了什么 | 交付 |
|---|---|---|
| **A 已成型** | 谁、在哪、干什么、什么调子都有 | 1 条，直译，不擅自加内容 |
| **B 有主体没画面** | 「猫耳少女」 | 1 条 ＋ 一行"补了哪几处" |
| **C 只有方向** | 「来点夏天的」 | 2–3 条不同方向 |
| **D 完全空白** | 「随便写点什么」 | 2–3 条，至少一条走非常规机位 |

- 用户说了条数就听用户的。
- 「给点想法」「随便」「都行」「你决定」→ 按 C/D 给多条。
- 只给了作品范围没点名角色 → 也是 C 档，给 2–3 组不同选角。
- **不许空手反问**：信息不全时先按最合理理解给成品，把不确定写成一行。
- C/D 的多条方案：差异必须落在**题材或动作**层，只换发色不算两条；末尾各一行说明偏在哪。

## 2 · 情境因果锁（内部构建，不输出）

```
发生了什么 → 情感/欲望/冲突 → 具体反应（表情+肢体） → 环境如何参与 → 最抓眼球的瞬间
```

- 必须有因果链：起因 → 反应 → **可见后果**。
- 单人图也要有内在张力。
- NSFW 同理：下流动作为因，表情/姿态/体液为果。
- 只挑一个瞬间，不描述连续剧情。

### 因果可见性

- 每个关键动作必须产生至少一个可见后果。
- 环境必须影响角色/道具/服装/头发/表情/构图层次。
- 情绪必须落到表情、视线、手势、身体重心或距离变化。
- **手部动作写清接触对象、位置、结果**（左右手分开说）。
- 看不见后果的动作不写；无法归属的复杂动作改写进 NL。

## 3 · 视觉简报（7 字段）

主体 / 场景容器 / 动作·关系 / 镜头距离+视角 / 光影方向 / 主体占比 / NL 提示。

- 多角色逐个绑定：位置 ＋ 角色 ＋ 2–4 个外观锚点 ＋ 动作。
- 默认保护脸部可读性。
- 不写世界观解释、文学比喻、情绪长文。

## 4 · 八维补全（至少触发 3 维）

| 维度 | 缺失表现 | 补全方向 |
|---|---|---|
| 互动 | 各自独立摆 pose | 对视、触碰、动作呼应 |
| 情感 | generic smile | 微表情 ＋ 身体语言 |
| 视线 | 都看镜头或闭眼 | 对视、偷瞄、看向画外 |
| 联动 | 环境是纯背景 | 风雨→反应、光线→塑形 |
| 动势 | 像摆拍立绘 | 重心偏移、布料飞扬 |
| 空间 | 贴脸平铺 | 前景遮挡、景深、留白 |
| 质感 | 塑料感 | 湿润反光、粗糙纹理 |
| 因果 | 不知道在发生什么 | 起因 → 当前姿态 → 暗示后续 |

单人图：互动维转为主体与环境的互动。补全内容必须服务于已有因果链，不能凭空插入。

## 5 · 槽位填充

| 槽 | 怎么填 |
|---|---|
| rating | 按画面 NSFW 程度选一个 |
| 人数 | `1girl` / `2girls`… ＋ `solo`（仅单人） |
| character | 版权角色写 `角色名 (作品名)`；**没换装就到此为止**，不要再列发色瞳色 |
| 外貌 | 原创角色用户给的锚点**一个都不许精简/替换** |
| 服装·配饰·道具 | 品类 ＋ 材质 ＋ 状态；**全裸就不写任何服饰 tag** |
| 动作·姿势·表情·视线 | 姿势一律用 tag |
| 镜头·构图 | 取景 / 视角 / 焦点各挑一个 |
| 场景·背景·氛围 | 场所 > 物件 > 时间天气 > 光影；背景形态只选一种 |
| NL | 空间 / 归属 / 接触 / 视线 / 光源 / 景深 / 因果 |

**角色名**：只认 danbooru 的英文或罗马音写法，不要拿中文名顶上；不确定拼法就写
「名字 (作品名)」并在附注里标一行。

## 6 · 写 NL

NL 段按**四个岗位**的顺序写。它们本来就是构思时的四个决定，这里只是把它们落成句子。

| 岗位 | 构思时决定了什么 | 落笔 |
|---|---|---|
| **① 编剧** | 有记忆点的那一下 | 句子：进行中的动作、因果后果 |
| **② 监督** | 空间、相机、景别、视觉中心、前中后景 | 机位/取景用 tag；**占画幅、前后层次、遮挡用句子** |
| **③ 原画** | 谁、什么动作、谁对谁做了什么 | 人数/姿势/表情用 tag；**施受、接触点、参与度用句子** |
| **④ 摄影** | 光、色、对比、质感 | 方向用 tag 兜底；**光源性质、第二光源、色温、对比、材质用句子** |

### ① 编剧 · 写正在发生的那一下

- 写清画面**停在哪个瞬间**、这个动作会产生什么**可见后果**。
- 想不出有记忆点的那一下时：**先排除这个题材最常见的五种普通构图**，再从这几处找新鲜感——
  相机位置 · 人物距离 · 裁切 · 遮挡 · 透视 · 动作 · 与环境的互动。
- ⚠️ 不要靠花瓣、粒子、星星、光效、大量漂浮物制造虚假的丰富感。

### ② 监督 · 写空间与层次

- 先说清相机高度、观看方向、景别、视觉中心，再写前 / 中 / 后景。
- 说清主体**占画幅多少**、谁离镜头近、前景挡了什么。
- ⚠️ 不要默认所有人物同样大小、全部全身出镜、站在同一平面。
  近景人物可以只露局部，中景承担主要动作，远处人物应当明显缩小。
- 可优先考虑：低机位 · 俯视 · 贴近前景 · 隔着物体观察 · 边缘取景 · 局部遮挡 · 倒影 · 门窗或镜面框景。
- **所有尺度与遮挡必须服从同一个明确的相机位置**，不能各自为政。

### ③ 原画 · 写归属

- 判据：**能不能回答"谁对谁做了什么"**。
- 逐人写：位置 · 远近 · 裁切 · 姿势支撑 · 动作方向 · 道具归属 · 视线。
- **接触点必须有主人**：写"A 的手压在 B 的手背上"，不写"她们的手碰在一起"。
- 写明参与度：施加 / 承受 / 旁观 / 不在场。
- 用**外观指认**角色，不要用编号。

### ④ 摄影 · 写光与色

- 主光方向与性质 · 第二光源 · 色温 · 对比 · 材质。

### 展开顺序：信息量从大到小

**先定的决定后定的，反过来会互相打架。** 六格依次是：

```
① 题材 / 场合  → 决定后面所有格的取值范围
② 谁           → 人数、体征。人数一变，构图整个换一套
③ 在干什么     → 动作 · 互动 · 表情
④ 在哪         → 场景 · 时段 · 道具
⑤ 怎么拍       → 取景 · 视角 · 构图 · 主体占幅
⑥ 什么调子     → 光线 · 色温 · 对比 · 氛围
```

- **调子最后定**，因为它得服从前面五格。常见的反向错误：先想好「黄昏逆光」再凑人和场景，
  结果场景是室内、逆光无处可来。
- 多方案时，**差异要落在①那一层**：三条方案如果"有意思的那一下"是同一种，
  换再多格也还是同一张图。

### 决定某样内容进 tag 还是进 NL

对每一样内容只问一句：**这一样必须钉死吗？有没有现成的词能钉？**

有词能钉 → 写 tag；没词能钉 → 用句子说清。**不是放弃，是换笔法。**

### 句子约束

- **离散事实用 tag，关系用句子**。姿势、人数、机位、取景**一律 tag**；写进句子会把姿势画糊。
- 不用人称代词；不加引号；不与 tag 层重复。
- 句式可用 `Place / Use / Keep / Frame / Light / Blur` 起句，一句一个职责。
- 单人 2–3 句，多人 3–5 句。

## 7 · 冲突检查

| 冲突对 | 规则 |
|---|---|
| `solo` vs 多人 | 选一个 |
| `close-up` vs `full body` | 选一个景别（`wide shot` 可与 `full body` 叠） |
| `from above` vs `from below` | 选一个 |
| `closed eyes` vs `looking at viewer` | 选一个 |
| 裸体 vs 任何服饰 tag | 选一个着装状态 |
| 背景形态 | 只选一种 |
| 多角色属性 | 绑到具体角色，不串 |
| 室内光源 vs 室外背景 | 光源和背景同空间 |

写完跑一遍机器校验：

```powershell
& "$SKILL\.venv\Scripts\python.exe" "$SKILL\tools\anima_validate.py" --tags "<tag 串>" --nl "<NL>"
```

## 8 · 自查

| ❌ | ✅ |
|---|---|
| 姿势写成句子 | 姿势写 tag，关系写句子 |
| 叠两个背景形态 | 只选一种 |
| 版权角色补一堆发色瞳色 | 没换装就只写 `girl, 角色名` |
| 原创角色把用户给的锚点"优化"了 | 一个都不动 |
| 全裸图还写 `thighhighs` | 全裸不写服饰 tag |
| NL 里用 `she` | 用角色身份或 `the character` |
| NL 重复 tag 层内容 | NL 只写 tag 写不了的关系 |
| 空手反问 | 先给成品方案 |
| 质量前缀 / 负面串 | 不产出 |
