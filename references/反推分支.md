# 反推分支（图 → 提示词）

触发：用户给了图片。输出恒为 tag ＋ 末尾几句自然语言，格式见 `格式规范.md`。

## 流程

```
1. 打标     wd_tagger.py → 带分数的 tag 列表
2. 分档     ≥0.8 直接采信；<0.8 的才回图判断
3. 判断+写NL 判误报 / 判属性轴（只针对 <0.8）＋ 写自然语言（NL 看整张图，不分档）
4. 组装+校验 槽位排序 → anima_validate.py
5. 输出     成品 + 一行不确定项
```

---

## 1 · 打标

```powershell
& "$SKILL\.venv\Scripts\python.exe" "$SKILL\tools\wd_tagger.py" "<图片>" \
    --general 0.35 --character 0.85 --json | Out-File run.json -Encoding utf8
```

- **阈值固定 0.35 / 0.85**。反推要优先召回——下游可以删（但只有 <0.8 的部分删得动，见 §2），
  而**没有任何环节能把没输出的 tag 找回来**。
  别用 0.5 以上：会切掉 `black eyes`(0.64)、`white hair`(0.64)、`single sock`(0.56) 这类真实内容。
  想更干净**不要提阈值**，在组装阶段按槽位裁剪。
- 输出特性：不输出画师与作品 tag；同槽多值是常态（`cardigan` / `grey_cardigan` / `brown_cardigan` 并存）。
- **这份 JSON 带每个 tag 的分数，是 §2 分档的唯一依据。**
  校验器的输出**不打印分数**——只看它就没法分档，等于把 §2 整节作废。

---

## 2 · 看图判断 ＋ 写 NL

> 下面第一小节的**分档只管「判断」**——图里有没有、属哪个轴。
> **写 NL 看整张图，不受分档约束**（NL 写的是关系与光影，本来就不是 tag 能覆盖的）。

### 先分档：不是所有 tag 都要你看

`run.json` 里每个 tag 都带分数。按分数分两档，**只对低档动脑**：

| 分数 | 怎么处理 |
|---|---|
| **≥ 0.8** | **直接采信**。不回图、不删、不怀疑。 |
| **< 0.8** | 走下面的 A / B 两件事。 |

`character` 类 tag 的阈值本身就是 0.85，**所以它们全部落在 ≥ 0.8 这一档，一律照用**。

### 角色身份不由你判断

**图片里的角色是谁，采信 tagger 的 `character` 输出，不要自己认人。**

- 它给了 → 照用。不改写法、不怀疑、不删。
- 它没给 → **就是没有** character tag。不许凭印象补一个人名，不许拿中文名顶上，不许顺带猜作品名。
- **你认得这张图是谁也不算数。** 你的识别不如这个专门训过的 tagger 可靠，而且「我觉得是 XX」无法校验。

### 判断（只针对 < 0.8 的那部分，两件事）

**A. 哪些 tag 属于同一属性轴。**
颜色、图案、构造、长度、姿势是**不同的轴**，同轴多值才是冲突。
跨轴可以并存：`blue skirt` 与 `plaid skirt` 是"颜色 vs 图案"，**都要留**。

**B. 哪些是误报。** 画面里没有的删掉。

**原则：宁可保留。** 拿不准的一律留，写进末尾附注。
把不同轴或不同角色的 tag 合并掉，会静默抹掉颜色、长度、姿势这些可复现的信息。

需要第二意见时才派子代理：给它图 ＋ **< 0.8 的那部分 tag**，要求它**只判断误报与属性轴、不执行合并、
只读整图一次不要切图、输出 ≤15 行**。

### 写 NL（同一轮里一起写）

NL 段按**四个岗位**对齐写：它们是把"画什么"翻译成句子的顺序，也是查漏的清单。

| 岗位 | 它决定了什么 | 落笔 |
|---|---|---|
| **① 编剧** | 有记忆点的那一下、正在发生的事 | 句子：进行中的动作、因果后果 |
| **② 监督** | 空间、相机、景别、视觉中心、前中后景 | 机位/取景用 tag；**占画幅、前后层次、遮挡用句子** |
| **③ 原画** | 谁、什么动作、谁对谁做了什么 | 人数/姿势/表情用 tag；**施受、接触点、参与度用句子** |
| **④ 摄影** | 光、色、对比、质感 | 方向用 tag 兜底；**光源性质、第二光源、色温、对比、材质用句子** |

#### ① 编剧 · 写正在发生的那一下

- 写清画面**停在哪个瞬间**、这个动作会产生什么**可见后果**。
- 图里同时发生好几件事时，**只挑最有张力的那一下**写，其余留给 tag 层。
- ⚠️ 不要靠花瓣、粒子、星星、光效、大量漂浮物制造虚假的丰富感——那是没想清楚时的填充物。

#### ② 监督 · 写空间与层次

- 先说清相机高度、观看方向、景别、视觉中心，再写前 / 中 / 后景。
- 说清主体**占画幅多少**、谁离镜头近、前景挡了什么。
- ⚠️ 不要默认所有人物同样大小、全部全身出镜、站在同一平面。
  近景人物可以只露局部，中景承担主要动作，远处人物应当明显缩小。
- 可优先考虑：低机位 · 俯视 · 贴近前景 · 隔着物体观察 · 边缘取景 · 局部遮挡 · 倒影 · 门窗或镜面框景。
- **所有尺度与遮挡必须服从同一个明确的相机位置**，不能各自为政。

#### ③ 原画 · 写归属

- 判据：**能不能回答"谁对谁做了什么"**。
- 逐人写：位置 · 远近 · 裁切 · 姿势支撑 · 动作方向 · 道具归属 · 视线。
- **接触点必须有主人**：写"A 的手压在 B 的手背上"，不写"她们的手碰在一起"。
- 写明参与度：施加 / 承受 / 旁观 / 不在场。
- 用**外观指认**角色（`the girl in the beige coat`），不要用编号。

#### ④ 摄影 · 写光与色

- 主光方向与性质 · 第二光源 · 色温 · 对比 · 材质。

#### 决定某样内容进 tag 还是进 NL

对每一样内容只问一句：**这一样必须钉死吗？有没有现成的词能钉？**

有词能钉 → 写 tag；没词能钉 → 用句子说清。**不是放弃，是换笔法。**

#### 句子约束

- **离散事实用 tag，关系用句子**。姿势、人数、机位、取景**一律 tag**——姿势写成句子会把姿势画糊。
- **不用人称代词**，用 `the character` / `the girl in the beige coat`。
- **不加引号**；**不与 tag 层重复**。
- 句式可用 `Place / Use / Keep / Frame / Light / Blur` 起句，一句一个职责。
- 单人 2–3 句，多人 3–5 句。

## 3 · 组装

按 `格式规范.md` 的槽位顺序排，空行分段。

---

## 4 · 校验

```powershell
& "$SKILL\.venv\Scripts\python.exe" "$SKILL\tools\anima_validate.py" --tagger-json run.json
```

它做四件事：规范化（小写 / 下划线→空格 / 括号保留）、上位词折叠、槽位冲突检查、精确 token 计数。

- 折叠规则：**中心名词相同** 且 **不是动词短语** 才折叠。
  `hat←witch hat` 折；`book←holding book`、`gun←gun sling` **不折**。
- 槽位冲突按属性轴报多值；**多主体自动跳过角色级槽位**；
  **分类词在场时豁免颜色互斥**（`colored inner hair` / `streaked hair` / `two-tone hair` 出现时，
  `blue hair` ＋ `pink hair` 是双色发，不是冲突）。
- 退出码 1 = 有需要定夺的项。

组装完成后用成品再校验一次：`--tags "<成品 tag 串>" --nl "<NL>"`。

---

## 5 · 冲突裁定

校验器**只报不裁**，按顺序裁。

⚠️ **§2 的 0.8 分档只免掉「图里有没有」的核验，不免冲突裁定。** 两个 tag 都高置信但打架时，
照样按下面顺序裁——所以第一条才是先看有没有分类词。

1. **分类词在场 → 不裁**，全留。
2. **看图裁**：回到图上确认到底是哪个颜色、哪个长度。
3. **分数裁**：看图也定不了时，留置信度高的。
4. **结构 tag 硬裁**：`solo` 与多人标记不可能同时成立，删一边（`2girls` 常是后景动物骗出来的误报）。

---

## 6 · 补盲（决定成品像不像）

tagger 的词表是闭集，**构图 / 光影 / 氛围给不出来**。对照图逐条问：

> ⚠️ 补盲**不包括角色身份**。tagger 没给出的角色 tag 就是没有，不要凭印象补（见 §2）。
> 下面问的是「画面里还有什么没被 tag 钉住」，不是「这人是谁」。

- 光线从哪来？逆光？斑驳光？
- 画面停在哪个瞬间？动作的可见后果是什么？
- 前景挡了什么？谁离镜头近？
- 有没有水印、文字、招牌？
- 有没有 tagger 漏掉的显著特征（发型扎法、护具、道具）？

能标签化的进 tag 层（`depth of field` `blurry foreground` `backlighting` `wide shot`），
其余进 NL 层。

---

## 输出

```
<tag 段：槽位顺序，", " 分隔，空行分段>

<NL 段：2–5 句>
```

末尾**最多一行附注**，只写不确定项 ＋ 兜底。例：

> 说明：`low twintails` 是低置信项（0.42），图上更像披散长发，已删；要双马尾请加回。

不写质量前缀、负面串、画师、作品名、流程解说。
